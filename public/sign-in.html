Changing two-factor authentication signs out every session. Keep backup codes somewhere private and separate from this installation. Password recovery does not remove two-factor protection.

Add a time-based account in your authenticator app: issuer BB SOC, six digits, 30-second interval, SHA-1. Enter the setup key below manually, or import the setup URI if your authenticator supports it. These are secrets: do not paste them into an AI agent, shared document, or QR-code website.

Two-factor protection is not active until you verify an authenticator code below. Leaving this page clears the displayed secrets; starting setup again replaces an unfinished setup.

Create the first account from the installation host using its loopback address, or run the local account command with this installation's existing state directory:

npm run account -- create --state-dir /absolute/private/bb-soc-state --email you@example.invalid --name "SOC administrator"

Replace the example path, email, and name with your own values. The command prompts for the password privately; do not put a password in a command or URL.

No shared default credentials. The first administrator is created once; additional accounts and password recovery are managed locally by the installation owner.
